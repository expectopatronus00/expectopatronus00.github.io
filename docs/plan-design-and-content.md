## 1. 现状诊断（用数据说话）

### 1.1 定位与文案的自相矛盾（最严重）

- `index.html:697-700` 原文：**"不追逐热点，只写下自己真的用过、验证过、值得保存的东西。"**
- 实际内容：121 篇中 **47 篇是搬运**（抖音 43 / 微信 3 / 小红书 1），占 39%。
- 后果：任何读者点开首页第一屏看到这句话，再点进"最近更新"，看到的是一排抖音视频改写稿——信任当场崩塌。
- **这不是内容问题，是承诺问题。** 归档站不丢人，假装原创才丢人。

### 1.2 信息架构混乱

- **分类维度混用**：21 个分类里，`抖音搬运 / 小红书搬运 / 微信搬运` 是**来源**维度，`AI工具 / AI编程 / AI应用 / AI技术 / AI教程 / AI资讯 / AI智能体 / AI量化` 是**主题**维度（且 9 个 AI 子类互相重叠）。两者平级并列。
- **标签墙**：459 个标签，372 个只用过一次。虽然 `TAG_VISIBLE=16` 做了折叠，但"展开全部 459 个标签"这个按钮本身就是设计失败的自白。
- **分类和内容对不上**：`?cat=AI` 只有 3 篇，`?cat=抖音搬运` 有 43 篇——分类按钮的颗粒度差异 14 倍。

### 1.3 首页的三个空转部件

| 部件 | 问题 |
|---|---|
| 主编精选 `.editorial-grid` | 4 张 Unsplash 图（机房 / 动漫人物 / 蓝色抽象）风格互斥；内容硬编码在 HTML 里，从上线至今没换过 |
| ON THIS ISSUE 面板 | 4 条内容同样硬编码，与左侧 hero 副标题语义重复 |
| hero-stats「6 topics」 | 假的。实际 21 个分类 |

### 1.4 缺失的基础设施

全站无 RSS、无 sitemap、无搜索、无 TOC、无阅读进度、无上下篇、无相关文章、无关于页。对一个"归档站"来说，**前四项是硬伤**——归档站的价值全在"找得到"。

### 1.5 已有资产（不要推翻）

- `home/design-tokens.css`（1062 行）是真正的资产：完整的色彩阶、字号阶、间距阶、组件类，且**做过 WCAG AA 对比度修正**（rust/jade 拆出 `-text` 变体，`--text-dim` 从 3.06:1 改到 6.01:1）。这套东西比市面上大多数博客主题做得好。
- `home/fonts.css`：自托管 Cormorant Garamond + Source Serif 4 可变字体（normal/italic 四个 woff2），中文走 emfont CDN 的霞鹜新致宋。**已经解决了 Google Fonts 在中国大陆不可用的问题**——这是很多中文博客没做到的。
- `scripts/repo-lint.cjs`（314 行）：已有文章数一致性、死链、孤链、重复检查。改造期间必须让它持续通过。

## 2. 调研结论：哪些该学，哪些不该学

调研了 12 个代表性站点（详见 `research/personal-blog-design-2026.md`），对本站有用的三条：

### 学 Julia Evans（jvns.ca）的归档页结构

她的首页不是"精选大图"，而是：**最近 10 篇 → 然后全部文章按语义分类成段展开**（Git / DNS / Terminals / Nix / Career / On learning…约 30 个桶，每桶内按时间倒序，条目前有 `★` 标记精选）。

**为什么这个结构对本站有效**：121 篇的体量，一个"按分类展开的全量归档页"比任何花哨的首页都更有用。而且它天然解决了标签墙问题——分类是**语义桶**（10 个上下），标签退回成行内元信息。

### 学 Dan Luu（danluu.com）的密度

纯 HTML 无序列表，每行 `月/年 + 标题`，无图无摘要，120+ 篇跨 13 年仍然可读。靠的是两列对齐 + 严格时间倒序。

**对本站的启示**：列表页不需要"日期 · 分类 · 标签 · 标题 · 摘要 · 箭头"六件套。**摘要可以砍掉**（在列表页），密度比信息量重要。

### 学 Lee Robinson（leerob.com）的"常青页"分离

他把内容分成 `## Notes`（10 条常青观点页：Things I believe / Understanding AI / Developer experience…）和 `## Blogs`（时间流文章）。

**对本站的启示**：这正是"系列文章"该长的样子——**系列不是标签，是独立入口**。

### 不学的部分

- **不学 craigmod / robinsloan 的图片驱动排版**——你已经决定砍图。
- **不学 kentcdodds 的吉祥物系统**——成本高，且与"归档站"定位不符。
- **不学 andymatuschak 的"无索引"设计**——那是给已经成名的人用的，归档站需要索引。

这是整个改版最关键的一步：

视觉效果：标题行后面跟一个 `转载 · 抖音` 的灰底小标签（原创则不显示任何标签，或显示 `原创`）。**读者一眼知道这是什么，且不影响按主题检索。**

## 6. 列表页（归档页）重设计

### 6.1 结构

```

  ↓
```

### 6.2 搜索实现

纯静态方案，不需要后端：

1. 写 `scripts/build-search-index.cjs`，从 `articles.js` 生成 `home/search-index.json`：
   ```json
   [{"i":0,"t":"标题","s":"摘要","c":"分类","g":["tag1","tag2"],"d":"2026-07-19","u":"../post/..."}]
   ```
2. 页面加载时 `fetch('search-index.json')`，输入框 `input` 事件里做子串匹配（标题权重 3 / 标签权重 2 / 摘要权重 1）。
3. ES5 写法，无依赖。

**为什么不在页面里直接搜 `window.articles`**：`articles.js` 有 1095 行 / 约 200KB，而搜索索引可以压到 60KB 左右。而且索引可以懒加载。

### 6.3 标签墙拆除

- 删 `home/home.html:317-319` 的 `#tag-pills` 容器
- 删内联脚本里 `TAG_VISIBLE`、`pill()`、`#tag-more` 相关逻辑（约 40 行）
- `?tag=` 查询参数保留兼容（老链接不 404），但页面上不再有入口

### 6.4 列表行调整

现在：`108px | 1fr | auto` = 日期 · (分类 + 标签 + 标题 + 摘要) · 箭头

改成：`108px | 1fr | auto` = 日期 · (标题 + 来源徽章 + 摘要) · 箭头

## 7. 文章页增强

以 `post/wx-openclaw/wx-openclaw.html`（342 行）为基准模板改造。118 篇全部套用。

### 7.1 新增：侧边 TOC（吸顶）

- 从正文的 `<h2>` 自动生成（ES5，`document.querySelectorAll('.article-body h2')`）
- 桌面端：`position: sticky`，固定在正文左侧（或右侧），当前章节高亮（IntersectionObserver）
- 移动端（< 1100px）：折叠成顶部一个「目录」按钮，点击展开
- 复用现有 `.section-marker` 的编号（`01 · 环境与目标`），TOC 条目直接显示这个编号 + h2 文本

### 7.2 新增：阅读进度条

顶部 2px 进度条，`--accent-rust`，滚动时更新 `width`。成本极低（~15 行 JS + 10 行 CSS）。

### 7.3 新增：上一篇 / 下一篇

文章页引入 `../home/articles.js`，按 `date` 排序找到当前文章的 index，取前后各一篇。**无需构建时预生成。**

### 7.4 新增：相关文章

同 `category` + tags 交集排序，取 top 3，卡片形式（无图，编号 + 标题 + 摘要一行）。

### 7.5 新增：来源声明块（搬运文章必备）

在 `.meta-row` 下方插入：

```
┌────────────────────────────────────────────────┐
│ 本文为转载整理 · 原文来自抖音 @<作者>             │
│ 原视频链接：https://www.douyin.com/video/xxx     │
│ 本站仅做学习归档，内容归原作者所有。              │
└────────────────────────────────────────────────┘
```

**这条比任何视觉设计都重要。** 它把"搬运"从道德负债变成透明的归档行为，同时解决 `skills/douyin-post-skill` 里 `.cta-box` 那个廉价感来源——现在的 CTA 是"去抖音看原视频"配一个泛搜索链接，改成结构化声明块。

- `/about/` —— 我是谁、这个站在做什么、转载政策
- `/now/` —— 现在在做什么（每季度更新）
- `/uses/` —— 在用什么工具（Claude Code / 服务器配置 / 硬件）
- `/colophon/` —— 这个站怎么做的（字体、配色、技术栈）

**成本极低（纯 HTML），但这是"个人博客"和"模板站"的分水岭。**

### 8.4 发布节奏建议

现在 121 篇集中在 2026-06-14 ~ 2026-07-19（一个月），之后停更。**归档站不需要日更**，建议：

- 转载：每周 2-3 篇，固定在周末批量处理
- 原创：每月 1-2 篇，宁缺毋滥
- 系列：一个系列完结再开下一个

## 10. 总体验收标准

改版完成后，这个站点应该满足：

1. **一个陌生人能在 10 秒内知道这是什么站**——首页第一屏的文案和实际内容一致。
2. **任何一篇文章能在 3 次点击内找到**——归档页分类展开 + 搜索兜底。
3. **每一篇转载都能追溯到原文**——来源声明块 + `source` 字段。
4. **RSS 阅读器能订阅**——`feed.xml` 通过 W3C 校验。
5. **长文能跳读**——TOC 吸顶。
6. **移动端可用**——断点 1024/768/680/420 全部检查。
7. **`repo-lint.cjs` 通过**——文章数、死链、孤链、重复全部为零。
