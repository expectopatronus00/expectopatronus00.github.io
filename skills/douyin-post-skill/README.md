# 🎬 抖音搬运文章生成 Skill

> 给我一个抖音链接，自动生成一篇结构完整的博客文章，并同步到首页 / 文章库。

## 这是什么

本项目（expectopatronus00.github.io）是一个运行在 GitHub Pages 上的个人科技博客。这一套 Skill 的作用是：**把一条抖音视频（作者口述+画面+字幕）转化为一篇图文并茂的深度文章**，自动融入整体视觉体系。

## 适用场景

- 你在抖音刷到了某条有深度的科技 / AI / 开发类视频
- 希望把视频内容整理成可长期索引、可搜索、可在 PC 浏览器阅读的文章
- 需要在文章中加入多平台跳转链接（原视频、官方站、论文、开源项目等）

## 如何使用

### 方式一：给 Agent 发消息（推荐）

把抖音 App 里的分享内容直接粘贴给 AI Assistant，格式大致长这样：

```
7.10 复制打开抖音，看看【AI风向标的作品】顶级AI模型遭封禁，Anthropic硬刚美国监管...
https://v.douyin.com/fv-r5ULbXH0/
02/17 :8pm WMJ:/ g@B.TY
内容文章合并，并实现多平台链接形成文章内容
```

或者简化版：

```
抖音视频: https://v.douyin.com/xxxxxxx/
标题: 你希望的文章标题
作者: AI风向标
```

**然后 Agent 会自动完成以下工作：**

1. 📱 打开抖音原视频，提取标题、封面、作者
2. ✍️ 撰写 800~1500 字的深度图文内容
3. 🧩 按统一模板生成一篇 HTML 文章
4. 🗂️ 自动更新首页排行榜、文章库列表
5. ✅ 做一次浏览器检查 + Lint 检查
6. 🚀 推送到 GitHub Pages 完成发布

### 方式二：手动基于模板创作

如果你想自己写内容，用模板文件 `template.html`：

```bash
# 1. 复制模板到新目录，按视频 ID 命名
mkdir -p post/dy-7651945427952078131
cp skills/douyin-post-skill/template.html post/dy-7651945427952078131/dy-7651945427952078131.html

# 2. 编辑 HTML，把 {{TITLE}} 等占位符替换为真实内容
#    完整的占位符清单见 SKILL.md 第 3.2 节

# 3. 更新 home.html 和 index.html 的文章列表
```

## 文章结构

每篇搬运文章都有以下**固定布局**，保证全站视觉一致：

```
┌──────────────────────────────────────────┐
│  🎬 英雄区：封面图 + 大标题 + 4 个元信息    │
├──────────────────────────────────────────┤
│  💡 简介 block：150~200 字一句话讲清主题   │
├──────────────────────────────────────────┤
│  📝 正文：5~8 个二级章节，穿插              │
│     • 时间线卡片（事件型内容）              │
│     • 引用 block（名人言论 / 核心观点）     │
│     • 高亮关键词                           │
├──────────────────────────────────────────┤
│  🔗 CTA 区：封面缩略图 + 看原视频 + 官方站   │
├──────────────────────────────────────────┤
│  🌐 多平台卡片：6~10 个相关延伸阅读         │
├──────────────────────────────────────────┤
│  🏷 话题标签：8~12 个 #话题                 │
├──────────────────────────────────────────┤
│  📰 相关文章：2 个站内已有文章链接           │
└──────────────────────────────────────────┘
```

## 视觉规范

- **主题色**：亮青 `#00e5ff` + 紫蓝 `#8b5cf6` 渐变
- **深色模式**：默认，可一键切换浅色
- **字体**：苹方 / 微软雅黑 / Segoe UI
- **响应式**：桌面 1200px / 平板 820px / 手机 480px
- **图标**：Font Awesome 6.5.2（CDN 自动加载，有备用源）

## 内容安全与版权说明

⚠️ **重要**

1. **不做逐字复制**：所有文章内容为 AI 原创重述，不是原文抄录
2. **保留原作者署名**：文章开头会标注抖音作者，CTA 区有"内容归原作者所有"提示
3. **不输出敏感内容**：涉政 / 医疗建议 / 投资建议 / 付费内容均不搬运
4. **仅学习用途**：本站为非商用博客
