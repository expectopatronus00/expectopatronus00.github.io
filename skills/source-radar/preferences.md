**硬结论**：
1. 点赞/收藏的 AI+科技纯度约 74%，点赞行为高度服务于「收集工具」——
   用户把点赞当**收藏夹**用，这是最强的偏好信号源。
2. **模型接入/免费通道是第一大类**（此前低估），信源关键词必带
   「免费模型 / 接入 / token / Claude Code 白嫖 / 中转」。
3. 短剧、游戏等噪声几乎不出现在点赞里（只在观看历史 binge）——
   评分闸门对「喜欢/收藏来源」可放宽生活类排除，对「观看历史来源」收紧。
4. 机器人/具身智能（宇树 H2-X 等）出现在未分类区，值得加入观察清单。

## 二、收录硬条件（不满足直接丢弃，不打分）

1. **有可验证实体**：能找到原始网站 / 开源仓库 / 论文 / 原视频链接，并核对过存在性
2. **来源标注完整**：作者、平台、发布时间至少有两项
3. **非重复**：与 articles.js 现有 121 篇标题相似度不撞车（含已删的「超级工程师」教训：同内容多平台搬运只留一份）

## 三、加分项

- 热度信号：抖音 10 万赞+ / GitHub 周 +3 千星+ / 创作者历史命中率（学霸妈妈讲AI、小乐数字纪元两个号已被验证）
- 「我能不能用它干成一件事」的实操空间——能跑通命令的优先于纯观点
- 官方出品或知名团队背书

## 四、减分项（命中两条以上降一档）

- 标题夸张化（「疯狂」「炸裂」「彻底变天」）——收录可以，标题必须重写
- 纯口嗨无实体（只谈趋势不给工具/仓库/方法）
- 内容与 AI / 效率 / 量化三主线无关的生活流量话题
- 营销号搬运痕迹（文案与已有文章雷同）

## 五、口吻基准

- 标题：去夸张化、点名实体（参考「一眼看清板块情绪：开源 A 股热力图 dapan.app」）
- 结构：事件是什么 → 怎么用 → 边界与冷思考
- 转载三件套：原文链接、作者、发布时间
