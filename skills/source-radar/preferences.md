## 〇、实测画像（2026-10-24 · 采样 204 条：抖音喜欢 58 / 收藏 39 / 观看历史 11 / 小红书浏览记录 96）

抽样统计的硬结论（按出现频率）：

1. **Agent Skills 生态是第一兴趣**：喜欢与收藏里 skill 合集、评测、教程类
   出现 12+ 次（机械设计 skill、AI 量化 skill×2、办公 skill、前端 UI SKILL、
   mattpocock skills、神级 skill、codex skills……）。信源关键词必带「skill 合集」。
2. **模型接入与免费通道**：免费模型接 Harness、永久免费 Claude Code、
   DSH token、零 token 操控电脑、API 中转评测——「白嫖 frontier 模型」类目稳定命中。
3. **GitHub 开源项目安利**：GitHub 周榜类、神级项目合集、「把全世界软件开源」
   类动向内容高频出现——与开源榜 Top 100 的运营方向完全一致。
4. **本地部署与硬件**：8G–32G 显存跑本地 AI 的选型内容被收藏；电脑整机配置类偶发。
5. **量化看盘工具**：板块情绪热力图（点赞 + 收藏 + 已归档成文）验证了这条线。
6. **噪声区（评分闸门直接排除）**：3D 漫剧/短剧连刷、游戏（三角洲行动）、
   宠物猎奇、生活好物（眼镜）、美食旅游——占浏览量约六成，但与博客主线无关。
7. AI 时代的职业讨论（对话孙宇晨、学编程有没有用）有中等兴趣，属成长线。

## 二、收录硬条件（不满足直接丢弃，不打分）

1. **有可验证实体**：能找到原始网站 / 开源仓库 / 论文 / 原视频链接，并核对过存在性
2. **来源标注完整**：作者、平台、发布时间至少有两项
3. **非重复**：与 articles.js 现有 121 篇标题相似度不撞车（含已删的「超级工程师」教训：同内容多平台搬运只留一份）

## 三、加分项

- 热度信号：抖音 10 万赞+ / GitHub 周 +3 千星+ / 创作者历史命中率（学霸妈妈讲AI、小乐数字纪元两个号已被验证）
- 「我能不能用它干成一件事」的实操空间——能跑通命令的优先于纯观点
- 官方出品或知名团队背书

## 四、减分项（命中两条以上降一档）

- 标题夸张化（「疯狂」「炸裂」「彻底变天」）——收录可以，标题必须重写
- 纯口嗨无实体（只谈趋势不给工具/仓库/方法）
- 内容与 AI / 效率 / 量化三主线无关的生活流量话题
- 营销号搬运痕迹（文案与已有文章雷同）

## 五、口吻基准

- 标题：去夸张化、点名实体（参考「一眼看清板块情绪：开源 A 股热力图 dapan.app」）
- 结构：事件是什么 → 怎么用 → 边界与冷思考
- 转载三件套：原文链接、作者、发布时间
