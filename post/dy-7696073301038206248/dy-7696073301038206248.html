一眼看清板块情绪：开源 A 股热力图 dapan.app

抖音 30 万赞的看盘神器：开源 A 股热力图 dapan.app，色块大小是市值、颜色是涨跌幅，板块轮动一眼可见。本文讲怎么读图、数据链路与自部署，顺带对比东财星图和大盘云图。

01 · 视频里在推荐什么

一张把全 A 股装进屏幕的图

这条视频在抖音拿了 30.1 万个赞：一张红红绿绿的矩形树图铺满全屏，半导体、消费电子、化学制药、国有大银行Ⅱ……几百个行业板块按体量挤在一起，颜色越红涨得越多，越绿跌得越狠。配文一句话：这个网站，能让你一眼看懂大 A 的板块情绪。

视频演示的网站叫 dapan.app，背后是一个 MIT 许可的开源项目 wenyuanw/a-share-heatmap，Next.js 加 Canvas 2D 实现，可以自己部署到 Vercel。它最近刚登上 GitHub 趋势榜，和这条视频的传播基本是同一波。

02 · 怎么读这张图

面积是体量，颜色是情绪

热力图的读法只需要记住两句话：色块面积代表流通市值权重——块越大，这个板块在市场里的体量越大；颜色深浅代表当日涨跌幅——红得发紫是涨疯了，绿得发黑是跌穿了这个月的底线。

所以一张图扫过去，你得到的第一个信息是「今天钱在哪个方向」：大块头是红的，指数大概率差不了；红色集中在几个小块上，那就是存量资金在题材里打转。第二个信息是轮动——昨天全绿的行业今天翻红，比任何文字复盘都直观。

交互上该有的都有：滚轮缩放钻到个股、悬浮看详情、涨跌幅周期可切换（当日 / 5 日 / 年初至今）、自选股高亮，还能一键截图分享到群里装深沉。

03 · 数据从哪来

东方财富的名册，腾讯的行情

开源项目最怕数据断供，这个项目的处理相当务实：股票名册、市值、行业分类取自东方财富全市场数据，价格与涨跌用腾讯批量行情接口刷新，服务端做秒级缓存；远端接口不可用时，回退到仓库内置的快照数据，保证页面永远打得开。

更稳的是它有一个 GitHub Actions 工作流，每个工作日北京时间 18:30 自动刷新股票池。也就是说就算作者哪天不管了，这张图的数据链路也能自己转。不想依赖别人的服务器，fork 下来一键部署到 Vercel 就有了自己的版本。

04 · 同类工具

三张热力图怎么选

这类树图不是新发明，主流的有三张，定位各有不同：

东方财富大盘星图：官方出品，数据和 App 完全同步，胜在权威和稳定；缺点是页面重、广告多，截图发群总带着别人的 Logo。

大盘云图（52etf.site）：老牌第三方，支持历史复盘，功能最全；界面风格比较「炒股软件」。

dapan.app：胜在干净、快、无广告，代码开源可自部署，适合不想被任何平台绑住的投资者。三张图数据源大同小异，选哪张更多是界面偏好问题。

05 · 冷思考

热力图能看什么，不能看什么

热力图最大的价值是把「结构」变成一眼可见的东西：今天涨的是大权重还是小题材、轮动往哪边切、哪些板块拥挤到发紫。这些信息以前的看盘软件要切七八个页面才能拼出来。

但它也有清晰的边界：颜色只告诉你「涨了多少」，不告诉你「为什么涨」。把颜色深浅当成买卖信号，和看 K 线数波浪没有本质区别。热力图适合当盘面结构的第一眼仪表盘，配合成交量、资金流向和消息面使用——图是地图，不是导航。

文中提到的工具仅为信息整理，不构成任何投资建议。市场有风险，决策需独立。
