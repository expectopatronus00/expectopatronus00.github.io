Skill 模板验证：一篇测试文章

AI 测试员 2026-06-16 1 分 30 秒 测试 · 结构验证
这是一篇由 douyin-post-skill 模板生成的测试文章。目的是验证：封面图加载、CSS 样式正确、时间线/引用/多平台卡片等组件正常渲染、主题切换可用、滚动条进度正常。

一、验证文字内容与小标题

本节验证基本的段落、高亮文字、以及 加粗文字 能否正常显示。排版的行高、边距、段距需与设计稿一致。

三级标题验证

三级标题颜色应为主青色（cyan），字体比正文略大，上方应有 22px 留白。

二、时间线组件验证

时间线用于展示事件型内容，有两列栅格布局：左侧时间、右侧描述。

Day 1
提取模板结构，分离 CSS / JS 到独立区域。
Day 2
定义 占位符规范，编写 SKILL.md 调用指南。
Day 3
生成示例文章、验证浏览器渲染、推送 GitHub Pages。

三、引用 block 验证

一个可复用的 Skill，本质上就是把"怎么做"从人的脑子里移到了文档里，让 AI 也能按同样的流程稳定产出。

四、正文段落与滚动

请滚动页面，观察顶部进度条是否随滚动位置线性变化，右下的"返回顶部"按钮是否在滚动超过 300px 后渐显。

点击右上角月亮/太阳图标，可切换深色/浅色主题；主题选择会存在 localStorage，刷新不丢。
