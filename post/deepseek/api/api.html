DeepSeek API 接入速查

本文是 DeepSeek 开放平台 API 的一页速查：模型列表、接口协议、curl / Python 调用示例与常见问题。所有示例以 DeepSeek 官方 API 文档为准，本页仅做整理。

01 · Models

可用模型

DeepSeek 开放平台当前对外暴露的主要模型及用途如下。在 API 调用中以 model 参数的字符串形式传入。

模型名 能力 常见用途
deepseek-chat 通用对话 日常问答、总结、翻译、代码助手
deepseek-reasoner 推理 / R1 数学题、逻辑推理、代码调试
deepseek-vision 视觉理解 图像内容识别、图表解读、OCR
02 · Endpoints

接口与协议

DeepSeek API 遵循 OpenAI 兼容协议。你可以直接用 openai SDK 切换 base_url 接入；也可以直接用 curl / 任何 HTTP 客户端访问。

Base URL： https://api.deepseek.com
认证方式： HTTP Header Authorization: Bearer sk-xxxx
获取 Key：DeepSeek 开放平台控制台
03 · cURL

cURL 示例 · Chat Completion

curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxx" \
  -d '{
    "model": "deepseek-chat",
    "messages": [
      {"role": "system", "content": "你是一个有用的助手。"},
      {"role": "user", "content": "你好，请简单自我介绍。"}
    ],
    "temperature": 0.7
  }'
04 · Python

Python · 使用 openai SDK

from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxx",
    base_url="https://api.deepseek.com"
)

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是一个有用的助手。"},
        {"role": "user", "content": "用 3 行介绍你自己。"},
    ],
    temperature=0.7,
)

print(resp.choices[0].message.content)
05 · Streaming

流式输出（推荐）

from openai import OpenAI

client = OpenAI(api_key="sk-xxxx", base_url="https://api.deepseek.com")

stream = client.chat.completions.create(
    model="deepseek-reasoner",
    messages=[{"role": "user", "content": "计算 12345 × 6789 的结果"}],
    stream=True,
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
06 · FAQ

常见问题

Q1. 接入提示 401 / invalid api key？
检查 API Key 是否正确复制；确认控制台中该 Key 状态为启用；部分环境需要为 HTTPS 配置代理。
Q2. context length 超限如何处理？
deepseek-chat 提供 128K 上下文。若依然超限，建议截断历史消息、或使用 vector store + RAG 方式处理长文本。
Q3. 国内服务器直连不稳定？
可以通过代理或中转服务转发；也可部署开源 DeepSeek 模型到本地 GPU 或使用 OpenClaw 做本地推理代理。
Q4. 如何降低成本？
合理控制 max_tokens、使用合适的 temperature 以避免冗长输出；复杂逻辑优先用 reasoning 模型而非在普通对话中反复尝试。
Q5. 官方文档与 Playground？
api-docs.deepseek.com 为最新文档；平台侧提供在线 API Playground 与用量统计。
