AI写的UI巨土？开源工具+设计系统直接根治

抖音博主「Tony讲实话」指出了AI编程的一个痛点——AI生成的UI界面「巨土」。功能能跑，但设计感约等于零。这篇文章带你了解AI生成UI为什么丑、用什么开源工具可以「直接根治」、以及如何让AI写出专业级界面。

01 · AI写UI为什么「巨土」

功能能跑，设计感为零

抖音博主Tony讲实话指出了一个AI编程的普遍痛点——AI生成的UI「巨土」。你让ChatGPT、Claude写一个页面，代码能跑，功能也对，但视觉效果就像2010年的网页：默认蓝色按钮、毫无层次的布局、没有间距感、配色一言难尽。

为什么会这样？根本原因有三个：

  • AI缺乏设计审美——AI学的是「代码」，不是「设计」。它知道怎么写CSS，但不知道什么是「好看」
  • 默认样式太基础——AI倾向于用最朴素的HTML标签和默认样式，没有设计系统加持
  • 缺乏设计上下文——AI不知道你的品牌色、字体风格、间距规范，只能用「通用」方案
核心问题：AI不是不会写代码，而是没有「设计系统」可以依赖。给它一套成熟的设计系统，它就能写出专业级的界面。
02 · 根治方案：设计系统+组件库

让AI站在巨人的肩膀上

Tony提到的「开源工具直接根治」，核心思路是：不要让AI从零写CSS，而是让它用成熟的设计系统和组件库。

🎨 什么是设计系统？

设计系统是一套完整的视觉规范——包括色彩、字体、间距、阴影、圆角、动画等，保证UI的一致性和专业感。Material Design、Apple HIG都是设计系统的代表。

🧩 什么是组件库？

组件库是设计系统的代码实现——把按钮、卡片、表单、导航等UI组件封装好，开发者直接调用即可。Bootstrap、Ant Design、shadcn/ui都是流行的组件库。

💡 为什么能「根治」？

当AI使用成熟的设计系统时，它不需要自己决定配色、间距、圆角——这些已经由设计系统定义好了。AI只需要选择合适的组件、组织布局结构，就能输出专业级UI。

03 · 主流开源工具盘点

哪些工具能让AI写出好看的UI

⭐ shadcn/ui — 当前最火

基于React + Tailwind CSS的开源组件库，不是npm包，而是「复制粘贴」的组件集合。你把组件代码复制到项目中，完全可控。AI对shadcn/ui的支持极好，因为它代码清晰、文档完善。Tony视频中很可能推荐的就是这类工具。

🎯 Tailwind CSS — 原子化CSS

用utility类（如flex p-4 rounded-lg）直接在HTML中写样式。AI对Tailwind的掌握非常好，因为它的类名就是设计决策——用Tailwind等于内置了一套设计系统。

📦 Radix UI — 无样式组件

提供可访问性（a11y）完善的「无样式」组件，你可以自由定制外观。shadcn/ui底层就用了Radix。功能靠谱，样式自由。

🎨 DaisyUI — Tailwind插件

在Tailwind基础上提供预制的组件类名，如btn btn-primary。比纯Tailwind更快，比完整组件库更轻。

🔧 其他选择

还有Chakra UI（React生态，主题强大）、Mantine（功能丰富的React组件库）、Ant Design（国内最流行，企业级）、NextUI（设计感强，现代风格）等。

04 · 如何让AI写出专业UI

实操指南

  • 指定设计系统——在prompt中明确要求：「使用shadcn/ui组件库」「基于Tailwind CSS」「遵循Material Design规范」
  • 提供设计上下文——告诉AI你的品牌色、风格偏好：「使用深色主题，主色为靛蓝，风格简洁现代」
  • 给参考——「参考Linear的UI风格」「像Vercel官网那样的设计感」——AI能理解知名产品的设计语言
  • 分步生成——先让AI搭整体布局骨架，再逐个细化组件，不要一次性生成整个页面
  • 使用设计token——定义CSS变量（颜色、间距、圆角等），让AI在token约束下写样式
  • 善用AI IDE——Cursor、Windsurf等AI IDE对shadcn/ui等流行库的支持更好，能直接预览效果
  • 迭代优化——AI第一版不会完美，通过对话迭代：「增加卡片间距」「把按钮改成圆角」「加一个微交互」
⚡ 高效Prompt模板

使用 React + Tailwind CSS + shadcn/ui 创建一个 [页面类型] 页面。要求：深色主题、主色#6366f1、卡片式布局、响应式设计、参考 [参考产品] 的视觉风格。

关键原则：不要让AI「自由发挥」设计——给它约束（设计系统），它才能发挥得好。就像给画家一套专业颜料和画布，比给他一支铅笔画油画要靠谱得多。
05 · AI生成UI的未来

从「能跑」到「好看」到「惊艳」

  • 设计系统原生化——未来的AI编程工具会内置设计系统，生成的UI默认就是专业级
  • 多模态输入——可以直接给AI看设计稿、截图、参考网站，让它「照着做」
  • 实时预览+迭代——AI生成UI后可以实时预览，通过对话微调，所见即所得
  • 个性化设计语言——AI学习你的品牌风格、个人审美，生成符合你品味的UI
  • 设计+代码一体化——从Figma设计稿到代码，AI全流程打通，设计感和代码质量同时保证
06 · 结语

工具对了，AI也能做出惊艳的UI

AI写的UI「巨土」？那是因为你没给它对的工具。

给AI一套成熟的设计系统——shadcn/ui、Tailwind CSS、Radix UI——它就能从「能跑就行」进化到「专业级界面」。核心不是AI能力不够，而是没有设计系统的约束，AI就只能在默认样式的泥潭里打转。

正如Tony讲实话所说：一个开源工具，直接根治。这个「根治」的本质，是让AI站在专业设计系统的肩膀上——工具对了，AI也能做出惊艳的UI。
