UI Skills集合：让AI写的前端从「能用」升级到「惊艳能卖」

AI写前端，最容易翻车的不是「跑不起来」，而是「能用但丑」——按钮能点但间距歪、配色脏、CTA藏得深、读屏软件读不出来。这8个UI Skills把人类设计师的审美和规范「喂」给Claude Code/Codex，从UI生成、设计系统、Tailwind样式到动效、无障碍、转化，按一条完整的设计工作流串联，装上它们，AI写出的前端才配得上「惊艳」两个字。

01 · 痛点剖析

为什么AI写的前端，总差那么一口气？

先说个扎心的共识：Claude Code、Codex 这类 Agent 写代码很快，但「设计」很弱。

它知道怎么写一个能跑的 React 组件，但不知道：

  • 间距用 8 的倍数还是随便来（结果页面全是 13px、17px 这种诡异数字）
  • 配色该遵循什么色板（结果一个页面出现 7 种「差不多」的蓝）
  • CTA 按钮该放在哪、写什么文案（结果注册按钮灰扑扑地缩在角落）
  • 无障碍要满足 WCAG（结果对比度不够，视障用户根本看不清）

这些不是「编码问题」，是「设计问题」。而解药就是前端设计 Skills——它们把设计师的审美、规范、checklist 压缩进一个 SKILL.md，让 Agent 在写前端时自动遵循。

AI slop 的定义：技术上正确，但视觉上与任何其他 AI 生成的界面 interchangeable（可互换）。

什么是 Skill？ Skill 本质上是为 Claude Code 注入的领域专业知识包。它们让 Claude 在特定场景下具备专家级的判断力和执行力。与系统提示不同，Skill 采用条件加载——只在任务匹配时才激活，不占用上下文窗口。

03 · 逐个拆解

8个Skill深度解析

🎨 No.1 UI Design Engine — UI 设计生成引擎

解决痛点：从 0 到 1 生成界面时，Agent 容易给出「能用但毫无美感」的布局。

它做什么：根据需求，生成符合现代审美趋势的 UI 布局和组件方案。不是套模板，而是结合设计原则（层次、留白、视觉动线）给出有设计感的方案。

什么时候用：新页面/新组件起步阶段，让设计有个高起点，而不是从「默认丑」开始慢慢调。

💡 典型用法

「帮我设计一个 SaaS 定价页，三档套餐，主推中间档，要有现代感」

📐 No.2 Design System Enforcer — 设计系统执行器

解决痛点：组件写着写着就跑偏——按钮圆角忽大忽小、字号乱跳、颜色越用越多。

它做什么：强制所有组件遵循你定义的设计令牌（design tokens）——统一的颜色、字号、间距、圆角、阴影规范。一旦定好设计系统，生成的代码自动对齐，保证全站一致性。

什么时候用：团队有设计系统（或想建立一套）时。这是从「一个能用的页面」到「一套一致的产品」的分水岭。

💡 典型用法

「按我们 design-tokens.json 里的规范，重构这个表单组件」

💨 No.3 tailwind-expert — Tailwind 专家

解决痛点：Tailwind 写起来快，但容易写出一堆反模式——类名堆成山、自定义值乱用、响应式断点乱来。

它做什么：用 Tailwind 的最佳实践写样式——优先用工具类而非任意值（[...]）、合理拆分组件类、正确使用响应式前缀和深色模式变体。生成的 Tailwind 代码更干净、更可维护。

什么时候用：前端样式实现的高频场景，几乎每个页面都要用到。这是8个里装机率最高的一个。

💡 典型用法

「用 Tailwind 实现这个卡片，要支持深色模式和移动端响应式」

✨ No.4 Motion & Interaction Designer — 动效与交互设计师

解决痛点：界面静态死板，缺少「活的感觉」——hover 没反馈、状态切换突兀、加载干等。

它做什么：为界面添加有意义的微交互和过渡动效——按钮 hover/press 反馈、模态框进出过渡、列表项加载动画、状态切换的平滑过渡。重点在「有意义」：动效服务交互，不是炫技。

什么时候用：界面骨架搭完后，提升「质感」的关键一步。好的动效能让「普通界面」显得「高级」。

✂️ No.5 Minimalist UI Simplifier — 极简 UI 简化器

解决痛点：AI 喜欢「加东西」——塞满信息、堆砌功能、恨不得一个页面放8个卡片。

它做什么：做减法。识别冗余元素、合并相似功能、精简视觉层级，让界面回归「少即是多」。遵循 Dieter Rams 的「好设计是尽可能少的设计」原则。

什么时候用：页面信息过载、视觉混乱时。特别适合 AI 生成的「大杂烩」页面做后处理。

💎 No.6 Impeccable — 设计打磨引擎

解决痛点：界面「差不多」但不够「精致」——细节粗糙、对齐不严谨、视觉节奏断裂。

它做什么：专治各种「AI 味」设计。从字体配对、色彩调和、间距节奏到视觉层次，逐项打磨，让界面从「能用」升级到「惊艳」。

frontend-design 这个 Skill 明确禁止了一系列被滥用的字体（Inter、Roboto、Arial、Space Grotesk），推动 Claude 在写代码前就确定一个具体的视觉方向。

♿ No.7 Accessibility Audit — 无障碍审核

解决痛点：AI 生成的界面经常忽略无障碍——对比度不够、缺少 alt 文本、键盘导航失效、ARIA 标签缺失。

它做什么：基于 WCAG 标准进行系统化审查，检查对比度、语义化标签、键盘可操作性、屏幕阅读器兼容性等。确保界面不只好看，还对所有人可用。

什么时候用：产品上线前必做的一步，尤其面向欧美市场或有合规要求的项目。

🚀 No.8 Conversion Optimizer — 转化率优化

解决痛点：界面好看但不「能卖」——CTA 不突出、信任元素缺失、转化路径断裂。

它做什么：从转化率角度优化界面——CTA 位置/文案/视觉权重、信任信号（评价/认证/保障）、紧迫感设计、A/B 测试建议。让界面不只是艺术品，更是商业工具。

04 · 进阶Skill

beyond UI：3个值得关注的进阶Skill

除了上述8个UI专项Skill，还有几个「元 Skill」和「流程 Skill」值得搭配使用：

🔧 skill-creator — 自定义 Skill 构建器

这是所有 Skill 的「元 Skill」——它让你能够创造、修改和优化属于自己的 Skill。掌握了它，你就从「Skill 的使用者」晋升为「Skill 的创造者」。

  • 创建新 Skill — 根据团队规范、项目需求，从零编写定制化 Skill
  • 优化已有 Skill — 对官方或社区 Skill 进行裁剪、增强
  • 评测与验证 — 测试 Skill 的触发效果，新增完整的技能评估和基准测试框架

🔍 ui-ux-pro-max — UI/UX 设计智审

一个涵盖了 Web 和移动端设计全维度的智能审查专家。不会直接给你代码，而是先出线框图描述、交互流程、再出视觉方案。

输出1
风格指南 — 根据项目定位推荐配色方案、字体组合、视觉风格
输出2
UX 规则检查 — 从信息架构、交互流程到可用性原则的全方位评估
输出3
组件建议 — 针对数据可视化、表单设计、导航结构给出专业建议

📋 ui-audit — UI 审核框架

基于成熟 UX 原则和系统化方法论的专业级界面审查工具。以业界公认的Nielsen 十大可用性原则为基准进行审查，按照预设的决策树和检查清单逐项排查界面问题。

05 · 安装使用

如何安装和使用这些Skill？

方法一：使用 skills-hub CLI（推荐）

skills-hub 是 Claude Skills 的开放注册表，支持一条命令安装：

# 安装单个 skill
npx @skills-hub-ai/cli install frontend-design

# 安装 code-review skill
npx @skills-hub-ai/cli install code-review

方法二：手动复制 SKILL.md

Skill 本质上就是一个 Markdown 文件，可以手动复制到项目的 .claude/skills/ 目录下：

.claude/skills/
├── frontend-design/
│   └── SKILL.md
├── ui-ux-pro-max/
│   └── SKILL.md
└── tailwind-expert/
    └── SKILL.md

方法三：在 Codex / Cursor / TRAE 中使用

这些 Skill 采用开放的 SKILL.md 标准，不只 Claude Code 能用——Codex CLI、Cursor、OpenClaw、TRAE、Qoder 都能装，真正做到一次配置，到处运行。

🚀 查看已安装的 Skills

在 Claude Code / Codex 中执行 /skills 命令，可以查看当前安装了哪些 Skills。

06 · 实战对比

装与不装 Skill，差别有多大？

以「设计一个现代化的登录页面，包含邮箱、密码输入框，支持深色模式切换」为例：

不装 Skill 的默认输出

  • 配色：默认蓝色按钮 + 白色背景，毫无辨识度
  • 字体：Inter 或 Roboto，AI 最爱用的「安全字体」
  • 视觉：扁平死板，没有任何质感
  • 深色模式：简单的黑底白字，对比度可能不达标

装了 frontend-design 后的输出

  • 色彩 — 深色模式使用深黑炭色 + 琥珀金点缀，浅色模式使用暖白 + 深灰
  • 字体 — Playfair Display（标题）+ Source Serif 4（正文），经典优雅的组合
  • 视觉 — 细腻的渐变背景、微妙的噪声纹理、精致的边框、流畅的动画
  • 差异化 — 金色光泽效果、玻璃拟态卡片、优雅的悬停动画

差别不是「能不能跑」，而是「能不能卖」。装了 Skill 的界面，从「AI 默认风格」变成了「有品牌感的产品」。

08 · 写在最后

AI时代的「设计民主化」

过去，好的前端设计是一门「手艺活」——需要多年的审美积累、反复的细节打磨。设计师和开发者之间，隔着一道「审美」的墙。

而 UI Skills 的出现，正在打破这道墙。它把设计师的专业知识结构化、可复用、可传播，让每一个用 AI 编程的人，都能产出有设计感的界面。

这不是替代设计师，而是让设计的专业判断力，成为每个开发者都能调用的「公共资源」。

当然，Skill 不是万能的。它提供的是下限保障——让 AI 生成的界面不至于太丑；而真正的上限，还是取决于你的审美判断、业务理解和对细节的追求。

🌟 行动建议： 如果你正在用 Claude Code、Codex 或其他 AI 编程工具写前端，强烈建议从 frontend-design 和 tailwind-expert 这两个开始装。这是性价比最高、效果最明显的两个 Skill。装上之后，同样的需求，输出质量会有肉眼可见的提升。
