本教程指导用户在 WorkBuddy 平台中部署两套 MCP Server，实现 AI 自动撰写、排版、推送微信公众号草稿的完整自动化链路。预计耗时 1-2 小时。

公众号凭证：AppID（后台直接显示）、AppSecret（启用/重置后仅显示一次，务必立即保存）、IP 白名单（访问 ip.me 获取本机公网 IP，在「设置与开发→开发接口管理」中配置）。服务号或订阅号均可，需已完成认证。

本地环境：Python ≥ 3.10、Node.js ≥ 18、npm ≥ 9、Git 任意版本。

网络要求：需能访问 mp.weixin.qq.com 和 GitHub。GitHub 直连困难时可使用 gitclone.com 镜像。

登录 https://mp.weixin.qq.com/，进入「设置与开发 → 开发接口管理 → 公众号开发信息」。AppID 直接复制保存。AppSecret 点击「启用」或「重置」→ 管理员微信扫码 → 输入密码 → 获取后立即保存。

访问 ip.me 获取本机公网 IP，在后台 IP 白名单中配置。未配置将导致所有 API 调用返回 errcode: 40164。

项目地址：https://github.com/kakaxi3019/wechat_oa_api_mcp

提供 5 个工具：get_access_token（获取 Token）、create_wechat_draft（创建草稿+上传封面）、publish_wechat_draft（群发）、del_wechat_draft（删除草稿）、del_wechat_material（删除素材）。所有参数通过 args 字段以 JSON 字符串传递，key 名为 appid 和 appsecret。

项目地址：https://github.com/caol64/wenyan-mcp，内置 8 种排版主题。

若 npx tsc 报 lib.d.ts 缺失：npm install typescript@5.9.2 --save-dev 后重试。若 npm 报 exit code 1，检查 node_modules/ 是否已创建（100+ 子目录），若已创建则直接编译。

提供 4 个工具：publish_article（排版+发草稿）、list_themes、register_theme、remove_theme。主题：default、orangeheart、rainbow、lapis、pie、maize、purple、phycat。

Markdown 文章需包含 frontmatter 声明标题、封面图路径、摘要和作者。封面图须为真实 PNG/JPG，推荐 900×500 像素。

关键区别：wechat_oa_api_mcp 不需要在 env 中配 AppID/Secret（调用时传参），wenyan-mcp 必须配置（进程启动时读取）。

在 WorkBuddy 连接器管理中分别点击「信任」激活。修改 mcp.json 后必须取消信任再重新信任，进程才会使用新配置，否则会报 invalid appid。

pip install 安装的是原版代码，存在两个缺陷。

修复一：Token 冲突。两个 MCP 同时调用 /cgi-bin/token 导致 Token 互相覆盖（errcode: 40001）。修改 /wechat_oa_api_mcp/core/constants.py 添加 stable_token 端点，修改 access_token.py 将 GET 改为 POST /stable_token。该接口允许多并发 Token 共存。

修复二：本地图片崩溃。create_wechat_draft 仅支持网络 URL，下载超时导致进程崩溃。修改 draft.py 的 download_image 函数，增加本地文件路径分支；修改 upload_media 的 finally 块，用 _is_local 标记保护本地文件不被误删。

修复后在 WorkBuddy 中取消信任再重新信任「微信公众号助手」即可生效。

序号验证项工具预期结果 1获取 Token`get_access_token``errcode: 0` 2创建草稿（本地图片）`create_wechat_draft`返回 `draft_media_id` 3删除草稿`del_wechat_draft``errcode: 0` 4删除素材`del_wechat_material``errcode: 0` 5列出主题`list_themes`返回 8 个主题 6发测试文章`publish_article`草稿箱收到文章

建议同时执行并发测试：两个 MCP 同时获取 Token 并创建草稿，验证 stable_token 修复生效。
