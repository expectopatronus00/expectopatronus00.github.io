Loop Engineering

Prompt 已死，Loop 已来！还在逐句调 Prompt 的你该醒醒了

还在一句句调 Prompt、改了又改？HeyGen 内部已经换了打法——Loop。一句话丢过去，Agent 自己把整条链跑完。变的不是模型，是协作方式。

01 · 从指令到目标

Prompt 正在失去它的光环

过去两年，Prompt Engineering 是 AI 浪潮里最耀眼的词汇之一。把提示词写得精致一些，大模型就能给出更准确的回答。但随着 Agent 能力的提升，这种「人写一句、机器做一步」的线性交互，正被一种全新的模式取代。

我们开始意识到：真正的瓶颈不再是如何把一句话写得更巧妙，而是如何让大模型自主地围绕目标持续工作。如果把 Prompt 比作「给机器递工具」，那么 Loop Engineering 就是「让机器自己在循环里找到最优路径」。

02 · Loop 是什么

一句话理解 Loop Engineering

Loop Engineering 的核心，不是写一句完美的 Prompt，而是为 AI 设定一个清晰的目标，让它在「执行 — 评估 — 调整 — 再执行」的循环里自主进化。

Prompt 是一次对话的艺术，Loop 是一段旅程的设计。

它不再依赖人类反复修改指令，而是让 Agent 在循环中不断逼近目标——就像一个优秀的实习生从失败中学习一样，大模型也在循环中自我进化。

理解 Loop Engineering 的三个要素：明确的目标函数、可度量的评估标准、以及能自我调整的执行机制。

03 · 一场范式的迁移

从「人驱动」到「目标驱动」

我们正在经历一次深刻的范式迁移。Prompt Engineering 让人人都能和大模型对话，Agent 让模型能做更多事，而 Loop Engineering 则让它在无人值守时仍然持续进步。

在这个新范式下，工程师的工作从「优化提示词」转向「设计反馈环」。人不再是每一步的指挥者，而是目标的设定者和循环的架构师。

04 · Loop 的结构

一个典型的 Loop 长什么样

一个健康的 Loop 至少包含四个环节：1. 目标设定 — 用可度量的语言定义什么叫做好；2. 执行动作 — Agent 根据当前状态选择下一步；3. 结果评估 — 对产出做客观评分，识别差距；4. 策略调整 — 基于评估结果反思并优化下一步策略。

一个能自动循环的系统，胜过一千个完美的 Prompt。

这四个环节反复运转，就形成了从「笨拙尝试」到「精准产出」的上升螺旋。

05 · 给工程师的新技能树

你需要重新学什么

如果你是一名正在向 AI 转型的工程师，Prompt 的技巧仍然有用，但它已不再是你安身立命的根本。Loop Engineering 要求你掌握三类新能力：

第一，设计清晰的目标函数和评估指标。第二，构建可观测的循环状态。第三，编写稳健的失败处理与重启机制。

一句话建议：比起研究 Prompt 模板，多花时间理解「大模型在循环里如何自我纠正」。

这不是要你放弃 Prompt，而是把它降格为 Loop 内部最底层的执行单元。真正值钱的，是那个让循环跑起来的架构设计。

06 · 属于你的 Loop 时刻

开始你的第一个 Loop

读完这篇文章，你不需要立刻重构整个系统。你可以从最小的一次尝试开始：挑一个你经常反复写 Prompt 的任务，把它从「单次对话」改造成「三到五次循环」，让大模型自己评估输出并做一次修正。

你会发现：让模型自己反思一次，比你改十次 Prompt 更有效。当你第一次看到 Agent 在循环里主动修正自己的错误时，你就会真正明白为什么说未来属于 Loop Engineering。
