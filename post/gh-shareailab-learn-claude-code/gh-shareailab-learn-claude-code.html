8 万星、17 课：Bash 是口号，Python 是正文

80,796 星的 learn-claude-code 用 17 课教人手搓 harness，口号是「Bash 万能」。17 份可运行代码全是 Python，两章占 42.3%；「完成率翻倍」没有实验。它是机制地图，不是产品。

02 核心机制

第一节只给模型一个 bash 工具和一个 while 循环；「Bash is all you need」说的是工具面，不是实现语言。

s01_agent_loop/code.py 里 TOOLS 只有一个条目，名字叫 bash。它用 Python 的 subprocess.run 执行模型给的命令，把 stdout 与 stderr 拼起来塞回 tool_result，没有结果就退出循环。

环节代码里的实际做法
工具数量1 个，名为 bash
执行方式Python subprocess.run(shell=True)；Windows 走 cmd.exe
危险命令拦截5 个固定子串：rm -rf /、sudo、shutdown、reboot、> /dev/
超时与截断120 秒超时；输出最多 50,000 字符
默认模型.env.example 写 claude-sonnet-4-6

每轮循环做三件事：把 assistant 回复整段追加进消息列表、执行其中所有 tool_use、把结果作为一条 user 消息回灌。循环由模型驱动，代码只负责执行和搬运。

  • 没有 tool_use 块：直接返回文本，结束本轮
  • 有多个工具调用：逐个执行，结果汇总成一条消息
  • 命令超时或不在白名单：返回错误字符串，仍作为工具结果回灌

后面每一章只加一个机制，循环本身不改。README 划了边界：s15 把累积运行时接回完整循环，s16 加工作流编排，s17 用更小的工具池讲目标续跑，明确不是又一个累积运行时。

这正是课程的价值：工具表、上下文压缩、任务图、权限边界被拆成可以单独读的 474.2 KB 代码，而不是藏在一个产品里。

04 怎么用

照 README 跑主线只要四条命令，但默认路径要 API key，而且新旧两条线的章节号不能混用。

  • git clone 仓库并 cd learn-claude-code
  • pip install -r requirements.txt，只有 anthropic、python-dotenv、pyyaml 三个依赖
  • cp .env.example .env，填入 ANTHROPIC_API_KEY
  • python s01_agent_loop/code.py 起步，再按缺口跳到 s08 或 s17
教程线入口范围状态
现行主线根目录 s01–s1717 章 + 三语 README + code.py推荐新读者
旧版过渡agents/ + docs/12 个可运行副本 + 12 课文档仅为旧链接保留

不想用 Anthropic 的官方端点，可以改 ANTHROPIC_BASE_URL 与 MODEL_ID。.env.example 列了 MiniMax、GLM、Kimi、DeepSeek 的兼容地址，同时提醒兼容不等于行为一致，课程不会替你抹平各家差异。

skills/ 只有 4 个技能目录、9 个文件共 54.6 KB，分别讲 agent 构建、代码审查、MCP 构建和 PDF；s07 拿它们演示按需加载。

网站是可选的。web/ 用 Next.js 从根目录课程抽取内容，npm run dev 可看 s16、s17 的阅读、源码、模拟和架构视图；学机制不必先跑前端。

05 冷思考

「完成率翻倍」写在课程格言里，s05 章节文档只说「更不容易漏步骤」，没有实验、样本或引用。

位置原文口径能核到的证据
README 课程列表s05「完成率翻倍」无基准、无样本量
s05 章节 README「复杂任务不太可能漏步骤」只描述提醒计数器逻辑
s05 代码连续 3 轮不写 todo 就注入提醒可以跑，但没有对照实验

数字式口号最容易脱离证据单独流传。这句「翻倍」不影响理解 todo_write 的机制，但它不该被当成效果承诺。课程里其他格言是设计原则，不是测量结果。

s01 的 5 个危险命令子串也不是沙箱：字符串匹配只挡固定写法，命令仍在宿主机 shell 里执行。它适合演示「工具接口长什么样」，不适合直接拿来跑不可信输入。

README 结尾把读者引向同组织的 Kode-CLI（5,238 星，Apache-2.0）与 kode-agent-sdk（410 星，MIT），还提到姊妹教程 claw0。课程本身也是产品入口，这不影响教程质量，但读的时候要分清哪部分是知识、哪部分是导流。

两条教程线并存也有成本：51 份章节译本要跟着英文改，开放 issue #611 就在指出 README-zh 有翻译不准和与英文不同步的行。新读者按主线读，旧链接迟早要迁。

把它当机制地图读最划算：先用 s01 看清循环，再按缺口挑 s08、s13、s17；别把 code.py 当生产 harness，也别把「17 课」当版本号。
