3.6万星、33毫秒：快的是旧引擎，学习要付费

36,005 星、3,219 fork，laya 在 11 月 26 日发布 v0.5.5。README 最显眼的一行写着「一次前向 33 毫秒、100+ 语言」，但同一份文档承认：这组数字属于经典编码器。真正的默认引擎与持续学习，另算。

01 这件事

36,005 星的 laya 把「一次前向、33 毫秒、100+ 语言」写在最显眼处，但这句话描述的是它不再默认的那一套引擎。

NandhaKishorM/laya 创建于 2026-09-18，11-26 仍在推送，主语言 Python，Apache-2.0。仓库简介称它是非自回归 System 1 决策引擎：typed choice、score 与 yes/no 决策一次前向完成，路由器按请求挑 checkpoint。

它入池时记 35,593 星，这次复核涨到 36,005，积压 11 天热度未衰减。首位贡献者提交 1,138 次，占 38.1%；账号数包含匿名账号，不等于实际人数。

02 核心机制

从 0.5.0 起，默认 Agent 已换成带 0.8B reader 的 Vega 引擎；33 毫秒那套要显式点名才会加载。

README 的 Quickstart 写得很直白：laya.Agent() 现在加载新引擎，底下是冻结的 0.8B reader，上面叠一个小型物理决策层；每种答案都带共形预测集、abstain 标记、分布外标记和算好的 route。

项目经典 checkpoint默认 Vega 引擎
上下文512 或 1,024 token，超出切窗73,728 token，整篇读
T4 文本延迟单条 32.8 ms，批量约 16 ms/条约 72 ms/条
从标签学习梯度微调agent.fit(rows)，秒级
输入类型仅文本文本、图像、音频、视频
拒绝策略自选 min_confidenceabstain、unbound、预测集与 route

路由器按固定顺序分流：图像和音频走 Vega，超过快模型上下文的长文本走 Vega，非英语或非拉丁文字走 Vega，装过拟合头的题目走 Vega，其余才用经典编码器。可强制指定模式。

新引擎的 unbound 只报告、不直接路由。README 自己给了原因：在正常 banking77 数据上它也有 71% 触发率，若照它分流，大部分正确答案会被送人工复核。

03 关键细节与数据

同一份 README 把「赢 Jev」和「基础 checkpoint 接近随机」放在同一页，摘任何一个数字都会失真。

路由表的数字来自仓库实测，Jev 一栏是第三方发布、仓库没有 API 亲自跑过，样本和提示都不同。两组数字不能当同一场考试的成绩单。

标签一多就翻车：77 个选项在默认 256-token 头预算里每个只分到三四个 token。README 把Banking77 失利归为架构性预算约束，建议调大 head_max_len、用嵌入做短名单，或走 predict_tournament 分组。

更硬的一句在「诚实限制」：基础 checkpoint 在 typed-decisions 零样本只有 0.362 与 0.352，随机基线 0.318、多数类基线 0.461。0.766 是拿该基准训练切分微调过的 checkpoint 跑出来的。

持续学习那组数字属于新引擎。14 个模板、31 个问题，每模板约 600 条生成样本，之后按确认答案增量学习，每模板留 60 条测试。

代价也算得清：300 条答案在 8 核 CPU 上 34 秒、6.4 GB 内存；同样 300 行微调传统编码器要 GPU 89 秒、9 GB，并重写全部 4.21 亿权重。

但学习功能不在 Apache-2.0 里。从 0.5.4 起，laya.Learner、laya.Escalator 和 laya.vllm_teacher 改由独立包 vegaml-learn 提供，采用 PolyForm Noncommercial 1.0.0，公司、产品或付费服务要另买许可。

04 怎么用

把它当可定制的本地判断层，别当开箱即用的通用分类器。

安装是一行 pip install -U laya，Python 3.10 起。要旧引擎就点名经典 checkpoint 或传 vegaml=False；要新增学习能力再单独装 vegaml-learn，代码不改。

  • 写问题：choice 给选项与描述，score 给有序等级，noul 给是否类判断。
  • 看输出：按 route 决定是否放行，不拿单一置信度做闸门。
  • 调长文：多语 checkpoint 默认 1,024 token，长文档须传 max_len=8192。
  • 调标签：超过 20 个选项先扩头预算，或先做短名单，或分组决策。
  • 做验收：在自己的数据上跑 fit / calibrate，再核对 ECE 与逐类错误。

自托管要补两处配置。SECURITY.md 写明：LAYA_API_KEY 不设时 laya-serve 无认证，默认又绑在 0.0.0.0:8000；非隔离环境至少要显式绑回环地址并设令牌。

该文件还限制了选项数不超过 100、单请求 token 预算默认封顶 8,192，并把并发缓冲请求限制在 16。这些是防资源放大的护栏，不是模型 accuracy 的保证。

05 冷思考

最该警惕的不是速度，而是三套口径被混着引用：旧引擎的速度、新引擎的能力、非商业包的学习。

项目把 Jev 的闭源 API 价格写进对比表，却承认对方数字不是自己测的；又把微调后的 0.766 和零样本的 0.362 并列在文档里。任何只搬最高分的转述，都比 README 本身更激进。

许可分层同样容易被忽略。主体 Apache-2.0 让代码可自由使用，学习组件却要商业许可；一个团队按「开源免费」立项，跑到第二个季度才会撞上这堵墙。SECURITY.md 的「支持版本」表还停在 0.3.x，而稳定版已是 v0.5.5，安全文档与发布节奏也没对齐。
