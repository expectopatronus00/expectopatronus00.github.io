1,686 星、15 天：poki 的 MCP 已停更

poki 建库于 2026-11-05，核对时 1,686 星、266 fork、AGPL-3.0。它让 iPhone 自己读屏、点击、输入；但 README 一句「no longer updated」，把早期 MCP 路线划掉了。

expectopatronus 2026-11-20 约 6 分钟阅读 原创 · AI 编程

01 这件事

一个建库只有 15 天的项目，把「agent 操作真 iPhone」做成了装进手机里的 app。JosssphZhou/poki 在 2026-11-05 建库，核对时有 1,686 星、266 fork，主语言 Swift、AGPL-3.0，11 月 20 日仍在推送。

它宣称的动词很朴素：读屏、点击、输入、滑动，都在真实 App 里完成，用的是你自己的模型账号。付款、删除和钱包操作会停下来等你确认；其余权限怎么问，由你选。

选题池给它的标签是「本地 MCP server 让 AI agent 操作真 iPhone」。这条描述已经过期：官方 README 把 MCP 归进了「早期工具」，明说它不再更新。

02 核心机制

现在的主线不是电脑上的 MCP server，而是装在 iPhone 上的 app。README 的安装从一台 Mac 或 Windows PC 开始：USB 连上并解锁手机，让编码 agent 按仓库的 AGENTS.md 装一次，之后手机可以独立运行，不必一直连着电脑。

官方在 README 里给了一句可复制的提示词，让 Claude Code 或 Codex 代为安装；也有 macOS 的 dmg 与 Windows 的 exe 安装包，按窗口走完即可。

差别不只在位置。MCP 那条路要从源码编译，前置条件是 macOS 15+、完整 Xcode、Rust、Node 24+、Python 3 和 ffmpeg；app 这条路明确不需要 Xcode，门槛低了一整层。

两套工具共存于同一仓库：skills/ 下既有安装技能，也留着 MCP 与 standalone 两份旧技能。老用户可以继续用，新用户被 README 明确导向 app。

04 怎么用

免费的是软件本身，真实成本在订阅和网络配置。装 app 之前要备齐五样东西：iOS 18+ 的 iPhone、Mac 或 Windows PC、USB 数据线、Apple 账号，以及一个自己的模型账号。

前置要求
iPhoneiOS 18+（XS/XR/SE2 及更新），实测 iOS 27 真机
电脑macOS 14+ 或 Windows x64，装 Apple Devices / iTunes
账号Apple 账号可免费；Poki Setup 续签 7 天免费签名
连接外部连接把 10.7.0.1 回环到手机，如 LocalDevVPN / Karing
模型ChatGPT Plus/Pro 登录，或 Anthropic / OpenAI / Gemini / DeepSeek 等 key

网络那一条最容易被忽略：手机要把 10.7.0.1 回环到自己身上，文档点名 LocalDevVPN、Karing 或 Shadowrocket。这不是装上就能用的工具，得先懂一点网络配置。

开发者模式、自动化模式、USB 首次配对、每 7 天续签名，是「无需越狱」换来的手续。README 给的验证任务是：在备忘录里建一条三行笔记，再打开确认内容。

权限上它做了分层：登录、验证码一律停下等你；支付、删除和钱包操作强制询问；其余可选四档敏感度。但文档免责写得很直白：Poki 不替你确认设备上的动作。

还有一条隐私边界：屏幕内容会发到你配置的模型服务。截图、聊天记录、支付页面都在这条链路上，用什么模型、跑在谁的服务上，决定了数据落在哪里。

0.4.0 之后它把界面整个换掉：三维熊首页、对话抽屉、灵动岛状态、Siri 与快捷指令入口都补上了；0.4.2 又加了 iPhone Duo 双 App 并排，以及新连接必须先在手机上同意的中继确认。

旧的 MCP 路线对平台更挑剔：官方只支持 macOS，Linux 与 Windows 各有社区移植，分别在 issue #16 和独立仓库维护，官方不测试。它默认用 GPT-6.1 Terra 低推理档跑手机任务，可用环境变量覆盖；这些细节都写在旧文档里，与 app 主线已经不是一套东西。

仓库把这条迁移摆得很明白：HANDOFF.md 有 27KB、docs/HANDOFF-standalone.md 有 27KB，还有一份 NOTE-FOR-JOSEPHS-AGENT.md。CHANGELOG 明说 Poki 与 Poki Runner 一起发版，每个版本先写给手机用的人，再写给底层。大量文字资产投在交接与说明上，是这类快速迭代项目的另一项显性成本。

05 冷思考

这条选题真正的问题不是「能不能操作 iPhone」，而是「操作到什么程度算可用」。验证文档给的是一台手机、一个搜索框、只测了点按；drag、pinch、横屏、底部浮动栏旁的按钮都明确没解决。

再看维护信号：MCP 与 Poki Agent 被标为不再更新，主线换到 app；版本号三套口径各说各话；仓库 92 个未结条目里，metadata 并不区分 issue 和 PR。建库 15 天涨到 1,686 星，热度主要来自「手机自己操作」这个想象。

更实质的约束是 Apple。native 桥接依赖 CoreSimulator 与真机私有接口，文档自己写「行为可能随系统版本改变」；签名要用你自己的 Apple 凭据，仓库不附带；横屏游戏、辅助功能尺寸都还在「未知」或「未实现」栏里。

对普通用户，7 天续签、外部连接回环、自备模型 key 这三件事，比「读屏点按」的宣传更决定体验。它省的是你在屏幕上点来点去的时间，花的是配置和排障的时间。

所以判断是：如果你已有一台开发机、一个模型订阅，需求是「在备忘录、点餐这类固定 App 里少点几十下」，可以试；如果你要的是开箱即用、横屏游戏也能托管的手机管家，README 的「no longer updated」和验证文档的 0/4 已经给了答案。
