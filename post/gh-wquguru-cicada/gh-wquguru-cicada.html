2,187 星、10 天 13 版：知了免费只落在一块芯片

2,187 星、375 fork、10 天 13 版，知了把实时字幕、同传和纪要铺到四个平台。但只有 Apple 芯片 Mac 的默认链路不填 key；README 说没有自己的服务器，仓库里却有一套分享用的 Worker、D1 与 R2。

01 · 这件事

2,187 星，一句「免费开源」背后有四套不同的条件

这个仓库把「免费开源」四个字拆成了至少三种条件，取决于你用的是哪台机器、填没填 key。

2026-11-01 建仓，11-12 核对时 2,187 星、375 fork、6 个未结 issue，Apache-2.0，主语言 Swift，最近一次推送就在 11-12。仓库描述写的是「Mac、Windows、Linux、Android 免费开源」。

节奏比星标更显眼。v1.0.0 于 11-03 发布，v1.9.0 于 11-12 发布，10 天 13 个版本，四个平台共用一个版本号。CHANGELOG.md 有 88,026 字节，列了 14 个版本段。

数字先摆成表。以下身份字段全部读自 api.github.com 的仓库接口，不引用仓库的 size 字段。

许可 / 主语言Apache-2.0 / Swift

README 备了中、英、日、韩四份，中文版 15,357 字节，是四份里最短的。本文引用的中文表述都以它为准。

但描述里那句「免费开源」，在 README 的平台表里被拆开了。四个平台不是同一套条件。

02 · 核心机制

四平台不是一次编译，是四种语言各写一遍

支撑四个平台的不是一套跨平台框架，而是 Swift、Python、C#、Kotlin 各写一份原生实现。

languages 接口合计 6,028,521 字节。四种主语言占比接近，正好对上四份平台目录，没有哪一种是「顺便编译出来的」。

平台差异不是实现细节，而是使用前提。README 平台表逐条列了系统要求与 key 依赖，照搬成表。

作者自己把这条边界写进了给编码 agent 的规则文件。AGENTS.md 第 16 行是：「Only Apple silicon Macs recognize on the device: don't claim 声音不出本机 for Intel or the ports」。

后面括号里那句更直白：a cloud AI service hears the audio。也就是说，「声音不出电脑」是有主语的，只指 Apple 芯片 Mac 的本机识别。

03 · 关键细节与数据

说「没有自己的服务器」，但 server/ 是一整套分享后端

README 那句「无统计、无埋点，也没有我们自己的服务器」，只在默认听写链路里成立。

它出现在「联网透明」条目下，前面列举了四个联网对象：translate.googleapis.com、你配的 AI 服务、下载 BlackHole 驱动、每天查一次 GitHub 更新。语境是听写与翻译时往哪发数据。

但同一个 README 又写着：点「分享…」能生成纪要链接，可选带上双语全文，设有效期和密码，上传前会自动拦截密钥、未公开公司信息等敏感内容。既然有「上传」，就有接收方。

接收方就在仓库里。server/ 有 13 个文件、59,370 字节，是一份可直接部署的 Cloudflare Worker 配置加源码。

来源文件实物内容
index.js 首行注释cicada.indaloop.app = 静态站点 + 分享服务，仅 /s/* 与 /api/* 走 Worker
wrangler.jsoncname 为 cicada-site；D1 库与 R2 桶都叫 cicada-share；Durable Object 为 Gate
wrangler.jsonccron「17 3 * * *」每天清理；SHARING=on；observability 开启
0001_init.sqldevices 表用 Ed25519 公钥标识设备、无账号；shares 表存元数据
shares.js纪要文档实体落到 R2 的 shares/<id>.json
review.js两个模型经 ZenMux 做上传前敏感审查

这不是「作者隐瞒了服务器」。准确说法是两条链路：默认听写只在需要翻译时把文字发给你选的服务；一旦主动分享，纪要就进作者的 Worker，D1 记归属与状态，R2 存正文。

分享链路的阈值写在代码里，都是硬数字，列成表比读句子清楚。

项目阈值
单次请求体2 MiB 上限
可选有效期7 / 30 / 365 天，默认 7 天
每设备活跃分享200
每日审查字符400,000
创建限流每设备每小时 20 次、每 IP 每天 100 次
阻断阈值BLOCK 0.85；命中操纵检测时降到 TIGHT 0.6
审查规则6 个问题 + 6 条固定格式密钥正则

review.js 的注释还记了一次国内故障：ZenMux 上的 Jev 会对被 Cloudflare 判定来自中国大陆的请求返回 451，原文写「stopped every share there」，于是改成先试 Cloudflare Clef。

这不算小问题。README 说分享链接能设密码和有效期，而该功能的审查链路一度对中国大陆请求整体不可用。功能清单和可用性要分开读。

04 · 怎么用

先决定填不填 key，再决定用哪台机器

最短路径是按平台下发行包，但「免费」的边界要到填 key 那一步才真正出现。

四个平台的包都挂在 Releases，可用 checksums.txt 核对 SHA-256。v1.9.0 共 11 个资产，主要发行包的大小与前置条件如下。

发行包（v1.9.0）大小系统要求前置条件
macOS AppleSilicon dmg18.57 MiBmacOS 14.4+默认链路无需 key
macOS Intel dmg18.74 MiBmacOS 14.4+需 Ling key
Windows x64 exe86.02 MiB10 2004+需 AI 服务 key
Windows ARM64 exe81.95 MiB骁龙 ARM64需 AI 服务 key
Linux tar.gz12.44 MiBUbuntu 22.04 / 24.04需 AI 服务 key
Android apk16.37 MiBAndroid 10+需 AI 服务 key

README 中文版对费用写得很具体：不填 API key，实时字幕、翻译、会议记录和同传全部免费；实时纪要、一步语音翻译、声音克隆要填自己的 Ling key。

成本口径是「开会一小时约 0.15 到 1 元」，Ling 每月送 10 元额度，够 10 到 50 小时。这句话只写在 Apple 芯片 Mac 的小节下，其他三平台识别本身就走云端。

功能填了 Ling key不填 / 退回
语音识别Apple 本机模型同左，仅 Apple 芯片 Mac
整句翻译Ling-3.1-flashGoogle 翻译或 Apple 本机
实时纪要Ling-3.1-flash不可用
同传听懂并翻译Ming-3.0-audio-flash本机识别 + 翻译链
同传发声与克隆Ming-3.0-tts-0.5BMac 自带语音，无克隆
说话人区分WeSpeaker ResNet34-LM（本机）同左

换句话说，不填 key 拿到的是字幕与记录，不是纪要。「AI 会议纪要」写在仓库描述里，却属于要 key 的那一档。

装之前还有几条会立刻撞上的限制，按清单记更实用。

  • 未签名：Mac 安装包目前没有苹果公证，首次打开要在「隐私与安全性」点「仍要打开」；Windows 会被 SmartScreen 拦。
  • 四项权限：录制系统声音、麦克风、输入监控、管理员密码；拒任一项只影响对应功能。
  • 虚拟麦克风：Mac 同传要装 BlackHole 2ch（GPL，用时下载、不打包）；Windows 是 VB-Cable。
  • 屏幕共享：Linux 纪要窗无法避开共享，窗口会标注「共享屏幕时此窗口可见」。
  • 数据落点：记录与录音在 ~/Library/Application Support/LiveSubs，卸载不会自动删。

路线图里「正式签名与公证」「不用 key 也有纪要」「iPhone / iPad」仍是待办。其中「自选 AI 服务」也在待办列表，但 README 正文已能填任何 OpenAI 兼容端点——路线图比实现慢了一拍。

许可证也要分开看：代码是 Apache-2.0，随附声纹模型是 WeSpeaker 在 VoxCeleb 上训练的 ResNet34-LM、按 CC BY 4.0 使用，虚拟麦克风 BlackHole 是 GPL 且不打包进安装包。

05 · 冷思考

10 天 13 版、四套原生代码，几乎全押在一个人身上

这个节奏不是社区活跃，是单人高频交付；星标还没转成协作。

commits 接口的末页显示 719 次提交，contributors 接口 6 人合计也是 719，两个口径正好对上。其中 wquguru 一人 713 次，占 99.2%。

贡献者提交数占比
wquguru71399.2%
其余 5 人合计60.8%
合计719100%

最近 100 条提交集中在 11-08 到 11-12 约四天里。一个人同时维护四种语言的客户端、一套 Worker、官网和四语言文档，还要每版发 11 个安装包。

6 个未结 issue 全是功能请求与兼容反馈，没有一条 PR；13 个 release 累计 7,488 次资产下载，最新一版 v1.9.0 只有 207 次。热度集中在「点一下」，不是「留下来」。

体量也有代价。完整 git tree 的 truncated 为 false，771 个节点里 642 个是 blob，合计 49,995,976 字节，约 47.68 MiB。

口径对象字节说明
git tree 逐 blob642 个文件49,995,97647.68 MiB，本文以此为准
三个声纹模型3 个文件33,211,512占全仓 66.4%
languages 接口只数源码6,028,5215.75 MiB

languages 不统计 bin、png、md、gif，与 tree 差 8.3 倍，两个口径不能相加。真正占地方的是随包附带的三份声纹模型，不是代码。

还有一处小口径差：tag 有 14 个、release 只有 13 个，v1.2.0 有 tag 没发版。版本数别按 tag 数算。

三处自我描述都要打折读：免费只在 Apple 芯片 Mac 的默认链路，无服务器只在默认听写链路，「四平台」是四份独立实现而非一次编译。作者其实比 README 更清楚边界，AGENTS.md 那句约束就是证据。

所以值不值得装，取决于手上是哪台机器。Apple 芯片 Mac、不填 key，能拿到一套完整的本机字幕；其余三种平台，换来的是一个要自备 key、把声音分段送出去的客户端。把「免费开源」当成需要读平台表的条件，而不是一句承诺。
