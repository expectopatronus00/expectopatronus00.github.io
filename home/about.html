关于这个站

这是什么

一个 AI 工具与实战的中文学习归档。原创的踩坑记录，加上精选的转载——每篇都标注来源。

建这个站的起因很简单：AI 领域的资料更新太快，今天看到的东西下个月就找不到。与其把链接塞进收藏夹里等着腐烂，不如整理成能读的形式，顺便逼自己把没想清楚的地方写清楚。

写下来，比记忆可靠；验证过，比抄来靠谱；整理好，比收藏有用。

这句话贴在首页，也是这个站唯一的标准。所以这里的转载不是「复制粘贴」：每一篇都重新组织过结构、补过上下文、标了原文链接和作者。如果你在某一篇里发现没标来源，那是我的疏漏，欢迎写信告诉我。

转载规则

这里的内容分两类，标注方式不同：

  1. 原创——标题旁有绿色的「原创」标记。是我自己动手做过的：部署、压测、写脚本、踩坑、复盘。
  2. 转载整理——标注来源平台（抖音 / 小红书 / 微信）。正文重新组织过，不是逐字稿；文末有原文链接和原作者。
  3. 转载内容只做学习归档，不做商业用途，不代替原文。如果原作者要求下架，我会立刻删除。
  4. 标题不做夸张化处理。原标题里的「炸了」「王炸」「神级」这类词会改掉——不是原文不好，是这个站的气质不适合。

这个站是怎么做的

没有框架、没有构建、没有数据库。就是一堆手写的 HTML、一份 CSS 变量表、和一个 JSON 一样的数据文件。这样做的好处是：十年后它还能打开。

托管
GitHub Pages，纯静态，无服务端
结构
HTML + CSS + 原生 JS（ES5 语法，不引入框架）
数据
home/articles.js 里一个 window.articles 数组，页面自己渲染
字体
拉丁文 Cormorant Garamond 与 Source Serif 4 自托管（woff2 可变字体）；中文走 中文网字计划 的 CDN 分片。不依赖 Google Fonts——它在中国大陆不可直连。
配色
深色底 + 赭橙强调色，另有一套暖纸浅色主题。所有文字对比度按 WCAG AA 校准过。
排版
正文每行 30–40 个汉字，行高 1.85，中文与英文、数字之间手动加空格
图标
内联 SVG，不加载图标字体库

想看看具体怎么写的，源码在 GitHub。
